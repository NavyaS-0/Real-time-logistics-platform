# Real-Time Logistics and Shipment Tracking Platform

An event-driven logistics platform for real-time shipment tracking,
ETA calculation, and shipment alerts.

## Services

- Shipment Service
- Tracking Service
- ETA Service
- Alert Service

## Infrastructure

- PostgreSQL
- Apache Kafka
- Redis
- Docker

## CI/CD

- GitHub Actions
- Docker images
- Trivy image scanning
- GitHub Container Registry
